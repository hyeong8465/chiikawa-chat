# 작업 규칙

## 필수

- 중요한 결정 → `docs/private/memory.md`에 기록(결정 / 대안 / 이유)
- `docs/private/` 내용(회사명, 작업 로그)을 공개 문서·코드·README에 옮기지 않음
- 프롬프트 원본은 git `character/`. Langfuse 프롬프트 관리 기능 안 씀
- 프롬프트 조립은 `app/prompt.py`만. 앱·평가 공용
- 모델 호출은 `app/llm.py`만. 공급자 고정·캐시 경계·Langfuse 기록 누락 방지
- 프롬프트 변경 → 평가 세트 재실행, 점수 하락 없을 때만 반영
- 채점 프롬프트 변경 → 골든셋 일치율 재측정
- 캐싱 동작은 usage로 확인. `cache_read_input_tokens`가 0이면 캐시 깨짐

## 금지

- 원작 사실(대사, 에피소드, 성격, 관계) 지어내기. 출처 있는 것만, 검수 전엔 "미검수" 표시
- 공식 이미지·로고, 과금·광고·상업 요소
- `data/raw/` 원본 자막 커밋. 요약·짧은 인용만 저장
- 시스템 프롬프트에 동적 값(날짜, 사용자명, 요청 ID). 필요하면 메시지 쪽에
- 대화 중 모델·시스템 프롬프트 변경
- 하치와레 상담사화(번호 매긴 조언, "그런 감정은 자연스러워" 등)
- MVP 범위 밖 기능 선제 구현(`prd.md`)

## 작업 방식

- 작업 성격 따라 모델 전환: 디자인·아키텍처·복잡한 로직은 상위 모델, 반복 수정은 빠른 모델
- 문제 보고 시 증상·환경·시도한 것 함께
- 첫 결과물은 불완전해도 됨. 고민보다 결과 보고 수정. 단 수정 결과는 평가로 확인
- 배포까지 해야 완성. 배포 환경에서만 나는 문제 있음
- 같은 실수 반복 → 이 문서 "금지"에 추가

## 라이브러리

| 용도 | 라이브러리 |
|---|---|
| 웹 서버 | `fastapi`, `uvicorn` |
| LLM 호출 | `openai`(OpenRouter가 OpenAI 호환) |
| 기록·평가 | `langfuse`(OpenAI 래퍼로 자동 기록) |
| 설정·데이터 | `pyyaml` |
| 자막 수집 | `yt-dlp`(스크립트 전용) |

- 새 의존성: 위 목록으로 안 될 때만. 이유는 `docs/private/memory.md`에
- 한글 웹폰트는 명시적으로 불러옴(환경 따라 깨짐)

## 제약

- OpenRouter Claude 요청은 공급자 Anthropic 고정(바뀌면 캐시 깨짐). GPT 채점자 요청엔 적용 안 함
- 크레딧 소진 판단: 402, 또는 403 + `error.metadata.limit_source`
- 스트리밍 중 오류는 HTTP 200 이후 SSE 데이터의 `error` 객체로 옴 → 상태 코드만 보지 않음
- IP 제한: Vercel 방화벽 `/api/*` IP당 10분 60요청. 하루 상한 없음. 앱 코드에서 IP 저장·전송 안 함
- 대화당 상한: 남용 방지용, 정상 사용자는 안 닿게. 값은 개발 중 결정
- 예산: OpenRouter 키 1개, 평가·서비스 공용. 소진 시 사용자가 충전
- 운영 모델: 평가 기준 통과하는 가장 싼 모델
- 전체 이용가
- 사고(thinking)·effort 설정은 지연·캐시에 영향. 채팅은 낮은 effort로 시작, 평가로 조정(파라미터 형식은 개발 시 확인)

## 에러 처리

| 상황 | 처리 |
|---|---|
| 스트리밍 전 오류(4xx/5xx) | 오류 코드 + 짧은 메시지 반환. 화면엔 캐릭터 톤 안내(예: "*고개를 갸웃한다* 어… 잠깐 말이 안 나와… 다시 말해줄래?"), 사용자 메시지는 입력창에 복원 |
| 스트리밍 중 오류 | SSE 오류 이벤트. 받은 글자는 지우고 위 안내(잘림·빈 답 포함, 저장 안 함) |
| 429, 5xx, 연결 오류 | 첫 글자 전에만 1초 뒤 1회 재시도, 이후 위 안내. 시간 초과(60초)는 재시도 안 함 |
| JSON 출력 | 2중 보호: 프롬프트로 JSON만 출력 + 파싱 실패 시 텍스트에서 JSON만 추출해 재시도 |
| JSON 최종 실패 | 추천 답변은 숨김(본 대화 무영향), 변환기는 재시도 안내 |
| Langfuse 전송 실패 | 사용자 응답 막지 않음 |
| IP 제한 초과(방화벽 429) | 화면이 하치와레 고정 문구 표시(서버 코드 관여 없음) |
| 크레딧 소진 | 모든 LLM 기능 중단, 하치와레 고정 문구, 대화 기록 유지 |
| 위기 신호 | 에러 처리와 별개. 프롬프트·평가로 보장, 세부는 개발 단계 |
