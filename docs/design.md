# 디자인

> 확정: 대화 화면 최종안(메신저형 + 감정별 얼굴 + 만화 말풍선 + 하늘·풀밭 배경). 말투 변환 화면은 추후 프로토타입으로 결정

## 제약

- 원작 그림은 하치와레 얼굴 5장만(감정별, 원작 그림을 잘라 160px로). 배경·장식은 직접 그린 무늬만. 팬아트·AI 생성 그림은 안 씀
- 권리자 요청 시 즉시 내림(하단 고지)
- 모바일 우선. 인스타 인앱 브라우저에서 깨지지 않을 것
- 밝은 화면 하나. 다크 모드는 MVP 이후

## 디자인 원칙

1. 원작 감성: 원작 그림체 같은 굵은 먹선, 둥근 손글씨 한글 글꼴. 꾸밈 최소, 주인공은 대사
2. 캡처 기준 1순위: 대화 화면을 캡처해 인스타 스토리(9:16)에 올렸을 때 예쁠 것. 화면 껍데기(상단·탭·버튼)는 작게
3. 구조: 메신저형(말풍선). 만화 칸형·무대형은 비교 후 탈락
4. 힘은 한 곳에: 하치와레 만화 말풍선(굵은 먹선, 꼬리가 얼굴을 가리킴). 나머지는 조용하게
5. 하치와레 표시: 상단에 얼굴(최근 표정) + "하치와레", 말풍선 왼쪽 위에 그 응답의 감정 얼굴
6. 목소리 구분: 하치와레 대사 = 감자꽃(Gamja Flower), 사용자·화면 글자·지문 = 푸어스토리(Poor Story, 손글씨 계열이라 감자꽃과 어울리되 더 반듯해 구분됨. 고딕 계열은 손글씨 대사 옆에서 따로 놂)
7. 배경: 위 하늘색 → 아래 풀밭 + 풀 무늬(직접 그린 SVG). 같은 하늘 아래 앉아 있는 장면

## 스타일

| 요소 | 값 |
|---|---|
| 먹선 | `#2A2522` 2.5px(하치와레 말풍선·얼굴·입력창), 사용자 말풍선은 머리색 `#7FA3C0` 2px |
| 하늘 | `#D9ECF7`(배경 위쪽, 전송 버튼, 확인 버튼) |
| 풀밭 | `#F2F1D5` 바탕 + 풀 `#9CC583` |
| 볼 분홍 | `#F2B8BF`(눌린 👍👎) |
| 보조 글자 | `#6B635C`(지문, 고지, 안내) |
| 글꼴 | 감자꽃(하치와레 대사, 이름, 구글 폰트), 푸어스토리(그 외, 구글 폰트). 손글씨라 작아 보여 1px씩 키움(본문 16, 칩 15, 지문 13.5) |

## 탈락 시안

| 시안 | 탈락 이유 |
|---|---|
| 색만 다른 메신저 3종(파스텔 하늘, 만화 칸 색감, 별 보는 밤) | 와닿지 않음. 평범한 메신저 앱 느낌, 원작 감성 부족 |
| 만화 칸형(응답 1개 = 1칸) | 메신저형이 더 나음(사용자 판단) |
| 무대형(큰 표정 고정 + 아래 기록) | 이미지 배제로 성립 안 함 |
| 이미지 없는 메신저(작업 11 1차) | 휴대폰 확인 결과 "싸구려 채팅 앱" 느낌, 하치와레랑 대화하는 느낌 없음. 반원 무늬가 하치와레로 안 읽힘, 자간·행간 넓음 |
| 비주얼 노벨형(큰 얼굴 + 마지막 대사 상자) | 지난 대화를 바로 못 봄. 메신저 + 얼굴이 더 나음(사용자 판단) |
| 위 무대 + 아래 대화 | 대화 칸이 좁아짐 |
| 메신저 + 얼굴, 크림 배경, 탭(작업 11 2차) | 두 말풍선이 같은 모양이라 주인공이 안 보임, 단어 중간 줄바꿈, 탭·👍👎·추천이 화면을 많이 차지 |
| 큰 타원 말풍선, 개구·주아 | 말풍선·글자가 너무 큼, 안쪽 여백 큼(사용자 판단). 감자꽃 선택 |

## 화면 구성

```
┌──────────────────────────────┐
│ (얼굴) 하치와레        [말투 변환] │ 상단: 최근 표정 + 이름 + "치이카와(먼작귀)"
├──────── 하늘 → 풀밭 ────────┤
│ (얼굴) 풀숲에서 고개를 내민다     │ 지문: 말풍선 밖 위, 작은 글씨
│      ◸ 앗… 처음 보는 얼굴이다…?  │ 만화 말풍선(대사만), 꼬리가 얼굴로
│        👍 👎                   │ 마지막 응답에만
│                이렇게 답해 볼까? │
│      [추천1] [추천2] [추천3] →  │ 내 쪽 점선 말풍선, 한 줄 가로 스크롤
│ (하치와레에게 말 걸기)      (↑) │ 둥근 입력창
│ 비공식 팬메이드, 비영리예요. …   │ 하단 고지(문장)
└──────────────────────────────┘
```

## 컴포넌트

| 요소 | 규칙 |
|---|---|
| 하치와레 말풍선 | 감자꽃 17px, 행간 1.35, 안쪽 여백 5/8px, 최대 폭 82%. 꼬리는 위쪽에서 얼굴을 가리킴. 대사만 |
| 사용자 말풍선 | 흰 바탕 + 머리색 선, 최대 폭 74%. 하치와레보다 한 단계 조용하게 |
| 줄바꿈 | 단어 단위(`word-break: keep-all`). 단어 중간에서 끊지 않음 |
| 지문 | 말풍선 밖 위, 푸어스토리 13.5px, 흐린 색, 기울임·`*` 없음(흐린 기울임은 읽기 힘듦) |
| 감정 얼굴 | 46px 원형, 말풍선 왼쪽 위. 지문 단어로 고름: 반짝·살랑·웃는·미소 → 기쁨("웃"만 쓰면 "갸웃"에 걸림) / 처진·눈물 → 슬픔(곁에 있기·위로는 평소) / 갸웃·머뭇·만지작 → 주저 / 쫑긋·동그랗 → 설렘 / 그 외 → 평소. 지문 없음(위기) → 슬픔. 자주 어긋나면 모델이 감정 표시하는 방식으로 |
| 👍👎 | 마지막 응답에만, 34px, 아이콘 17px. 같은 걸 다시 누르면 취소 |
| 추천 답변 | 입력창 위에 고정, 대화 위에 투명하게 띄움(대화가 칩 뒤로 지나감. 칸을 나누면 경계에서 말풍선이 잘려 보임). "이렇게 답해 볼까?" + 오른쪽 점선 말풍선 한 줄, 가로 스크롤, 14px. 여러 줄로 쌓으면 대화 칸을 4분의 1 가까이 덮음 |
| 말투 변환 | 상단 오른쪽 버튼으로 전환("말투 변환" ↔ "대화로"). 입력창 1, 결과 카드 2(의도 유지판, 비틀기판), 카드별 복사 버튼 |
| 첫 방문 안내 | 1회 모달: "AI가 만든 응답이며, 대화는 품질 개선을 위해 익명으로 기록돼요." |
| 하단 고지 | "비공식 팬메이드, 비영리예요. 답은 AI가 해요. 권리자가 요청하면 바로 내려요." |
| 스트리밍 | 생성되는 대로 글자 출력. 대기 중 "…" 표시 |
| 아이콘 | 선 아이콘(SVG). 이모지 금지 |
| 제한·소진 안내 | IP 제한 초과, 크레딧 소진 시 하치와레 말풍선 형태의 고정 문구. 입력창 비활성 |

## 간격·접근성

- 좌우 여백 14px, 말풍선 간격 10~14px
- 터치 영역 최소 44px(예외: 👍👎 34px, 추천 칩 40px — 화면 차지 줄이려고)
- 글자 대비 4.5:1 이상
- 한글 웹폰트 명시적으로 불러옴
