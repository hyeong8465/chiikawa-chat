# 디자인

> 확정: 대화 탭 최종안(메신저형). 말투 변환 탭 화면은 추후 프로토타입으로 결정

## 제약

- 이미지 전면 배제: 공식 그림·팬아트·AI 생성 그림 모두 사용 안 함(저작권). 분위기는 색·글꼴·선·여백으로만
- 모바일 우선. 인스타 인앱 브라우저에서 깨지지 않을 것
- 밝은 화면 하나. 다크 모드는 MVP 이후

## 디자인 원칙

1. 원작 감성: 손그림 같은 흔들리는 선, 넓은 흰 여백, 둥근 손글씨 한글 글꼴. 꾸밈 최소, 주인공은 대사
2. 캡처 기준 1순위: 대화 화면을 캡처해 인스타 스토리(9:16)에 올렸을 때 예쁠 것
3. 구조: 메신저형(말풍선). 만화 칸형·무대형은 비교 후 탈락
4. 하치와레 표시: 이름 없이 도형만. 하치와레 말풍선 왼쪽 위에 머리 무늬(파란 반원 + 가운데 흰 갈라짐)를 추상화한 작은 도형
5. 목소리 구분: 하치와레 대사 = 손글씨체 Gaegu(17px 이상), 사용자·화면 글자 = Gowun Dodum

## 스타일

| 요소 | 값 |
|---|---|
| 배경 | 흰색 `#FFFFFF` |
| 선 | 먹색 `#2B2B2B` 2px, 손그림처럼 비대칭 둥근 모서리 |
| 포인트 | 연한 하늘색 1개(사용자 말풍선, 하치와레 도형, 전송 버튼) |
| 보조 글자 | `#6E6A66`(지문, 고지) |
| 글꼴 | Gaegu(하치와레 대사, 제목), Gowun Dodum(그 외) |

## 탈락 시안

| 시안 | 탈락 이유 |
|---|---|
| 색만 다른 메신저 3종(파스텔 하늘, 만화 칸 색감, 별 보는 밤) | 와닿지 않음. 평범한 메신저 앱 느낌, 원작 감성 부족 |
| 만화 칸형(응답 1개 = 1칸) | 메신저형이 더 나음(사용자 판단) |
| 무대형(큰 표정 고정 + 아래 기록) | 이미지 배제로 성립 안 함 |

## 공통 화면 구성

```
┌─────────────────────────┐
│ 하치와레랑 얘기하기      │ 상단: 제목 + "치이카와(먼작귀)" 병기
│ [ 대화 ] [ 말투 변환 ]   │ 탭
├─────────────────────────┤
│ ◐                        │ 하치와레 무늬 도형(이름·이미지 없음)
│ *풀숲에서 고개를 내민다*  │ 하치와레 말풍선(지문 + 대사)
│ 앗… 처음 보는 얼굴이다…? │
│                    👍 👎 │ 응답별 피드백
│ [추천1] [추천2] [추천3]  │ 추천 답변 칩(누르면 전송)
│ ┌───────────────┐ [전송] │ 입력창(하단 고정)
│ 비공식 팬메이드 · AI · 비영리 · 권리자 요청 시 즉시 내림 │ 하단 고지
└─────────────────────────┘
```

## 컴포넌트

| 요소 | 규칙 |
|---|---|
| 말풍선 | 하치와레 왼쪽, 사용자 오른쪽. 지문·대사는 같은 말풍선 안에서 스타일로만 구분 |
| 지문 | 본문보다 한 단계 작게, 흐린 색, 기울임 |
| 첫 방문 안내 | 1회 모달: "AI가 만든 응답이며, 대화는 품질 개선을 위해 익명으로 기록돼요." |
| 말투 변환 탭 | 입력창 1, 결과 카드 2(의도 유지판, 비틀기판), 카드별 복사 버튼 |
| 스트리밍 | 생성되는 대로 글자 출력. 대기 중 "…" 표시 |
| 아이콘 | 선 아이콘(SVG). 이모지 금지 |
| 제한·소진 안내 | IP 제한 초과, 크레딧 소진 시 하치와레 말풍선 형태의 고정 문구(멘트 추후 결정). 입력창 비활성 |

## 간격·접근성

- 좌우 여백 16px, 말풍선 간격 8~12px
- 터치 영역 최소 44px
- 글자 대비 4.5:1 이상
- 한글 웹폰트 명시적으로 불러옴

## 결정 필요

1. 말투 변환 탭 화면(구현 6단계 전에 프로토타입으로)

## 최종안 참고

- 대화 탭: 디자인 캔버스 "최종안 · 메신저형"(390×844)
- 말풍선 도형 SVG: 파란 반원(`#9EC9F0`, 먹선 2px) + 가운데 흰 삼각 갈라짐, 말풍선 왼쪽 위 모서리에 걸침
- 하늘색 면: `#CFE4F7`(사용자 말풍선, 선택 탭, 전송 버튼)
