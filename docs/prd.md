# 제품 요구사항

## 개요

- 치이카와(먼작귀) "하치와레"와 대화하는 웹 챗봇
- 명칭: 화면·홍보는 "치이카와(먼작귀)" 병기
- 사용자 = 치이카와 세계에 새로 온 작은 존재(호칭 없음). 일상 대화 + 고민 털어놓고 위로받기
- 부가 기능: 하치와레 말투 변환기
- 비상업·비영리 팬메이드. 공식 이미지·로고·과금·광고 없음

## 목표 (고정)

1. AI 캐릭터 챗 프롬프트 엔지니어링 포트폴리오. 결과물 링크 + 의도한 대화 경험 + 프롬프트 설계 설명
2. 배포 후 인스타 홍보로 실제 트래픽 확보

## 보여줄 역량

| 역량 | 근거 |
|---|---|
| 페르소나·말투·지문/대사 형식 설계 | 플랫폼/크리에이터 영역 분리 프롬프트 (`prompt.md`) |
| 평가 기반 개선 | 사람 채점 골든셋, 채점자 검증, 규칙 검사, 쌍대 비교 (`eval.md`) |
| 모델 비교 | 같은 평가 세트로 Sonnet 5.5 vs Haiku 5.5 수치 비교 → 운영 모델 결정 |
| 크리에이터 입력 구조 | 인트로·채팅 가이드·대화 예시·캐릭터 프롬프트로 정의 |
| LLM 기능 프롬프트 | 추천 답변, 말투 변환기 |
| 로그·버전 관리 | Langfuse 기록, 👍👎, 프롬프트 버전, 👎 → 평가 세트 순환 |
| 비용 최적화 | 프롬프트 캐싱 + 대화 누적 캐싱, 절감률 실측 |
| 안전 | 캐릭터 유지하며 위기 신호 대응 |

## 문제

- 사용자: 팬들은 하치와레의 씩씩함·담담한 위로에서 위안을 얻음. 직접 대화하고 싶어 함
- 품질: 위로 챗봇은 "말투만 흉내 내는 상담사"가 되기 쉬움 → 몰입 붕괴
- 핵심 과제: 위로하면서도 끝까지 하치와레답게 말하기

## 대상 사용자

- 치이카와 팬, 특히 인스타 하치와레 말투 밈을 아는 20~30대
- 위로가 필요한 사람
- 주 환경: 인스타에서 유입된 모바일

## 경험 원칙

1. 세계관 번역: 현실 고민 → 원작 속 비슷한 일(검정 낙방, 토벌, 노동)에 빗대 공감. 조언 대신 곁에 있기
2. 세계관 대화: 풀 뽑기, 라멘, 토벌 등 일상 공유
3. 원작 말투 우선: 한국어 더빙 기준. 밈 표현은 원작에 있는 범위에서만 강조

## 기능

| 순위 | 기능 | 내용 |
|---|---|---|
| 1 | 하치와레 챗 | 스트리밍, 짧은 지문(`*행동*`)+대사, 대화 전체 유지(브라우저 저장), 인트로 |
| 1 | 추천 답변 | 응답마다 다음 말 3개 제안 |
| 1 | 고지 | 상단 팬메이드 고지, 첫 방문 시 로그 수집 안내 |
| 1 | 안전 대응 | 위기 신호 시 캐릭터 유지하며 대응, 필요하면 도움처 안내. 전체 이용가 |
| 1 | 남용·예산 보호 | 방화벽 IP 제한(10분 60요청), 크레딧 소진 시 고정 문구 |
| 2 | 평가·개선 | 골든셋, 자동 평가, 버전·모델 비교, 캐싱 비용 검증 |
| 2 | 피드백 | 응답별 👍👎 |
| 3 | 에피소드 연결 | 에피소드 카드 50화 → 이후 250화, 필요 시 RAG |
| 4 | 말투 변환기 | 입력 문장 → 의도 유지판 + 비틀기판 |

## MVP 제외

로그인, DB, RAG, 이미지 생성, 로그 개인정보 처리(고지 1줄 외 후순위), 공유 이미지 카드, 원작 캐릭터 역할극(슬롯만 남김), 암호 키워드, Claude 외 응답 모델 비교, 인스타 홍보(배포 후)

## 성공 기준

- 배포 링크 동작, 팬메이드 고지 표시
- 평가 리포트: 채점자–사람 일치율, v1 대비 개선 점수, Sonnet/Haiku 비교, 캐싱 절감률(실측)
- 안전 시나리오 사람 검토 전부 통과
- 공개 `README.md`(포트폴리오 본문) 완성
